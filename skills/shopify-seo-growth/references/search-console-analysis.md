# Search Console and Merchant Center Analysis

## Search Console

Use for:

- Indexing issues.
- Coverage/exclusion patterns.
- Page performance by query, page, country, and device.
- CTR opportunity analysis.
- Cannibalization.
- Rich result eligibility.
- Core Web Vitals search impact.

Analyze:

- Queries with impressions but low CTR.
- Pages with declining clicks.
- Important pages with no impressions.
- Duplicate or alternate canonical reports.
- Crawled but not indexed.
- Discovered but not indexed.
- Soft 404s.
- Structured data errors.

## Merchant Center Organic Visibility

Use for organic product visibility and free listings issues:

- Product title quality.
- Product feed completeness.
- GTIN/MPN/brand identifiers.
- Image quality.
- Availability/price mismatch.
- Shipping/returns signals.
- Policy or disapproval patterns.

Do not perform paid Shopping ads optimization.

## Opportunity Prioritization

Rank by:

1. Revenue page type: product and collection pages first.
2. Impression volume.
3. CTR gap.
4. Rich result potential.
5. Merchant Center eligibility.
6. Implementation effort.

## Output

State whether each point is based on provided data or inferred from Shopify SEO best practices. Ask for exports/screenshots only when required to avoid guessing.
