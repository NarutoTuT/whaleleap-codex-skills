# Theme Release Checklist

## Target

- [ ] Canonical store domain confirmed
- [ ] Local absolute theme path confirmed
- [ ] Remote theme ID, name and role confirmed
- [ ] Primary action classified

## Local State

- [ ] Theme structure confirmed
- [ ] Git branch, commit and dirty state recorded
- [ ] Approved file allowlist separated from unrelated changes
- [ ] Local deletions and generated files classified
- [ ] Relevant validation completed or explicitly unavailable

## Remote State

- [ ] Fresh theme list obtained
- [ ] Scoped drift classified
- [ ] Overwrite behavior explicit
- [ ] Remote-only files preserved by default
- [ ] Intended deletions individually approved

## Authorization and Recovery

- [ ] Exact action and target authorized
- [ ] Scope has not expanded since authorization
- [ ] Publication separately authorized when applicable
- [ ] Rollback point captured

## Verification

- [ ] Command outcome recorded
- [ ] Resulting theme ID and role verified
- [ ] Released files read back when material
- [ ] Preview or live URL recorded
- [ ] Partial or untested layers reported accurately
- [ ] QA and launch-readiness follow-up separated from release success
